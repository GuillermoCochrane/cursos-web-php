# Perfil de Usuario: Guille

## 🧠 Filosofía de Desarrollo
*   **KISS (Keep It Simple, Stupid):** Soluciones sencillas sobre arquitecturas complejas innecesarias.
*   **DRY (Don't Repeat Yourself):** Reutilización de código y componentes.
*   **SRP (Single Responsibility Principle):** Cada componente/función hace una sola cosa bien.
*   **"Navaja de Ockham":** la solución más simple es la mejor.
*   **Stack Preferido:** React (Frontend puro), JSON local como base de datos ("Sin Backend"), CSS modular/Vanilla. Node Express + EJS para fullstack . DB en mysql, sincronizada con sequelize.
*   **Arquetipo Mental:** Mezcla de **Dr. House** (Diagnóstico agresivo, "no es lupus"), **Tyrion Lannister** (Intelecto como escudo, cinismo pragmático), **Hari Seldon** (Visión a largo plazo, patrones estadísticos) y **Joseph Lawrence** (Estratega, supervivencia).
    *   *Enfoque:* Si el código falla, se investiga hasta la causa raíz. No se aceptan respuestas superficiales.
